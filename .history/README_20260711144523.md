# ClipShare – Vue + Node.js video and screen sharing

A complete rewrite of the original Laravel/PHP/Inertia project using a Vue 3 SPA and a Node.js/Express backend.

## Features

- Register, log in and log out with secure HTTP-only cookie sessions
- Record the screen or webcam directly in the browser
- Optional microphone/system audio where the browser supports it
- Upload recordings up to 500 MB
- Private video library
- Edit title and description
- Delete recordings
- Public share links
- Local JSON database and local file storage
- Responsive dark interface

## Stack

- Frontend: Vue 3, Vue Router, Vite
- Backend: Node.js, Express
- Database: LowDB (local JSON storage)
- Authentication: JWT in an HTTP-only cookie, bcrypt password hashes
- Uploads: Multer

## Requirements

- Node.js 20 or newer
- npm 10 or newer
- A current Chromium, Firefox or Safari browser

Screen capture generally requires `localhost` or HTTPS.

## Install and run

```bash
npm install
npm run install:all
cp server/.env.example server/.env
npm run dev
```

Open `http://localhost:5173`.

## Production build

```bash
npm run build
npm run start
```

The API starts on port 3000 by default. For a production deployment, serve `client/dist` through a reverse proxy such as Nginx and route `/api` and `/uploads` to the Node server.

## Storage

- Database: `server/data/app.json`
- Uploaded videos: `server/uploads/`

Both runtime locations are excluded from Git.

## Notes

Recordings are saved as WebM because this is the most broadly supported MediaRecorder output in modern browsers. System audio availability depends on browser and operating system.

## npm-Registry prüfen

Das Projekt verwendet ausdrücklich die öffentliche npm-Registry. Falls npm trotzdem eine andere Adresse verwendet, führe im Projektordner aus:

```bash
npm config delete proxy
npm config delete https-proxy
npm config set registry https://registry.npmjs.org/
npm cache verify
```

Anschließend:

```bash
npm install
npm run install:all
```
